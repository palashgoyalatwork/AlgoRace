# 🏁 AlgoRace

> **Same data. Different algorithms. One race.**

AlgoRace is an interactive sorting algorithm visualization and benchmarking tool built with Python and Streamlit.

It puts two sorting algorithms head-to-head on the **same dataset** and compares their behavior using live visualization, execution time, comparisons, and swaps/moves.

## 🚀 Features

- 🏁 Head-to-head algorithm races
- 📊 Interactive dataset visualization
- ⚡ Live sorting animation
- ⏱️ Execution-time benchmarking
- 🔢 Comparison counting
- 🔄 Swap/move counting
- 🏆 Automatic winner detection
- 🎚️ Adjustable dataset size
- 🔵 Bubble Sort
- 🟣 Selection Sort
- 🟢 Insertion Sort
- 🟡 Merge Sort
- 🟠 Quick Sort

## 🧠 Algorithms

| Algorithm | Average Time | Worst Time |
|-----------|--------------|------------|
| Bubble Sort | O(n²) | O(n²) |
| Selection Sort | O(n²) | O(n²) |
| Insertion Sort | O(n²) | O(n²) |
| Merge Sort | O(n log n) | O(n log n) |
| Quick Sort | O(n log n) | O(n²) |
